# ANGERI SUMANTH - AI Engineer Portfolio Website

A personal portfolio website for **Angeri Sumanth**, an **AI Engineer** specializing in Generative AI, LLM applications, RAG, and intelligent agentic systems, with a strong foundation in **full-stack Python development**.

Pure HTML, CSS, and vanilla JavaScript. No build step, so it deploys directly on **GitHub Pages**.

## Customize

- **Profile photo:** replace `assets/images/profile.jpg` with a different square picture anytime.
- **Project links:** each project card in `index.html` currently links to your GitHub profile. Search for `TODO` and replace them with the individual repository URLs.
- **Certificates:** add a credential link or ID where marked `TODO` in the certificate cards.
